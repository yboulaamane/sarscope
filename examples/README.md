# Examples and paper data

- [Paper datasets](paper_data/README.md): assay cohorts, 2D benchmark splits and
  predictions, plus hash-verified access to the original aligned 3D inputs.
- [Analogue-design examples](analogue_design/README.md): dataset builders and
  workflow demonstrations.
- Bundled [EGFR](../src/sarscope/data/field_example/README.md) and
  [CCR5](../src/sarscope/data/field_ccr5_example/README.md) 3D examples.

Dataset licences are separate from the MIT software licence. Example scores are
specific to their inputs and validation protocol, not guarantees for a new series.
