# Paper datasets

Frozen inputs and readable tables for the SARscope manuscript. Nothing here is
loaded automatically by Streamlit. No model was refitted to prepare these files.

| Dataset | Start here |
|---|---|
| BRAF, DRD2 and ER-alpha assay series | [SAR tables](sar/README.md): structures, measurements, final series membership and positional comparisons |
| Three-target 2D benchmark | [2D tables](qsar2d/README.md): 6,667 curated compounds, train/test membership, original predictions and frozen source records |
| Thrombin, AChE and steroid 3D sets | [3D inputs](qsar3d/README.md): activities, source partitions and verified SDF retrieval |

For the bundled EGFR/CCR5 tutorials, see [examples](../README.md).
The [recorded 3D evidence](../../benchmarks/field_qsar/README.md) provides the protocols.

Read [data attribution](DATA-LICENSE.md) before reuse.
[Checksums](manifest.sha256.json) identify every file in this folder;
[provenance](provenance.json) distinguishes original files from later exports.
An accessible Git snapshot is not a permanent archival DOI.
