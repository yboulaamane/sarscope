# Visual assets

- `sarscope-logo.svg`: editable wordmark on a dark surface, readable on both GitHub themes.
- `sarscope-mark.svg`: compact molecular-scope symbol for the app sidebar.
- `sarscope-hero.svg`: existing workflow illustration.
- `screenshots/`: real browser capture and provenance.

The brand combines a molecular ring and a scope, with teal, amber, coral and
violet accents matching the app. Artwork is local SVG, with no external fonts,
scripts or image-generation dependency. It is covered by the repository's MIT licence.
