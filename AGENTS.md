# Publication privacy

Never add, commit or push unpublished manuscripts, Supporting Information,
paper-specific figures, cover letters or journal-submission packages. These
materials are private and local-only, regardless of their filename or folder.
Keep manuscript recovery bundles and superseded-history branches private too.

The public repository is for software, user documentation and datasets that
the user has explicitly approved for publication. Before any push, inspect the
outgoing file list and stop if publication materials would be included.
