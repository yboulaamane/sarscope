# CCR5: measured, pre-aligned 3D-QSAR tutorial

This is the main example in **3D QSAR · own compounds**. All 75 published
CCR5 antagonist records are included. Experimental activity labels are kept
unchanged; none are synthetic or assigned from a model. Source: Aher et al.
(2007), with aligned SDF data deposited by Haga et al. (2025).

## Run it

1. Expand **Try a measured 3D-QSAR example**, select **CCR5 · 75 measured
   compounds**, and tick **Use measured 3D-QSAR example**.
2. If previous settings are still present, click **Restore example model
   defaults**. This clears results but does not prepare or train anything.
3. Keep **All compounds**, **Keep uploaded alignment**, and reference **CCR5_01**.
   Prepare the overlay, inspect it, and tick the alignment-review declaration.
4. Run the native CoMSIA-style field model: five fields, Gasteiger charges,
   2 Å grid, raw scaling, 30% per-field screening, at most four PLS components,
   three nested CV folds, 25% random hold-out, 19 permutations, seed 42.

For manual upload, use **ccr5_3d_aligned.sdf** and property **pactivity**.
The three-column **ccr5_3d.csv** is also provided, but contains no coordinates.
Generating fresh conformers from the CSV does **not** reproduce the supplied
alignment or guarantee the recorded results. No docking is involved.

## Actual results, not literature scores copied into the app

The current native pipeline fitted on 56 compounds and predicted 19 held-out
compounds using the default seed. Exact values and row-level predictions are
in `verification.json` and `predictions.csv`.

| Native model | Pooled nested-CV q² | Held-out R² | Held-out RMSE |
| --- | ---: | ---: | ---: |
| 3D field PLS | 0.499 | 0.642 | 0.521 |
| Same-split 2D ECFP4 Random Forest | 0.598 | 0.724 | 0.457 |
| Training-mean baseline | — | approximately 0 | 0.870 |

The primary 3D model selects two PLS components. Its q² is **below 0.5**;
rounding to two decimal places must not turn the failed check into a pass.
The 19-permutation p-value is 0.05, a coarse screen, not certification.
Native end-to-end validation remains incomplete. Positive held-out prediction
demonstrates a usable tutorial signal, not a qualified optimisation model.
The 2D RF wins on this split; its metrics are not attributed to the 3D model.

Four additional fixed seeds were evaluated without replacing primary seed 42:

| Repeat seed | Nested q² | Held-out R² | RMSE |
| ---: | ---: | ---: | ---: |
| 7 | 0.564 | 0.540 | 0.675 |
| 19 | 0.558 | 0.395 | 0.573 |
| 73 | 0.506 | 0.649 | 0.583 |
| 101 | 0.441 | 0.582 | 0.638 |

Every repeat is retained, including weaker results. These overlapping random
partitions are a split-sensitivity diagnostic, not independent replications.
This public cohort was previously inspected. Its original 63/12 benchmark
membership is preserved in `preparation.csv`; this tutorial's random 56/19
partition is different and does not replace the earlier frozen benchmark or
erase its poor external score. No seed, component count, label or row was
changed to select the best test score.

## What was prepared

The source molecules carry protonated amines. The app's existing upload
curation uses neutral-parent structures. This derivative therefore applies
that same existing standardiser **before upload**, without canonical tautomer
enumeration. It verifies by retained atom provenance that every heavy atom,
heavy-atom bond and heavy-atom coordinate is unchanged. Protonation and
redundant stereo representation changes are recorded per compound, rather
than silently moving coordinates to a different guessed structure. Hydrogens
are regenerated by normal field preparation. The neutral state is a modelling
assumption, not evidence of the assay protonation state or binding pose.

The reference is the compound with the fewest heavy atoms (identifier
tie-break), chosen without activities or scores. It makes common-core QC
more tractable; the supplied poses are not realigned. An alignment-QC defect
found during preparation counted duplicate symmetry combinations against the
mapping limit. The corrected implementation counts distinct atom maps and
still refuses genuinely truncated searches. This bug does not establish the
cause of the earlier EGFR example's negative scores.

No external QSAR executable, imported model, processed field matrix, joint
train/test scaling, or measured-test-mean correction is used. The CSV is a
coordinate-free structure/activity interchange file, not an alternative
pre-aligned benchmark.

## Design step and limitations

After the model, the optional analogue-design step uses this same fitted
3D PLS, grid, charges, feature mask and reference frame. Unmet validation
checks still require explicit exploratory consent, and geometry/domain
failures still withhold candidate scores. Supporting-pair disagreements are
flagged, not corrected by changing predictions.

The historical cohort has not been independently checked against all original
assay conditions. Before transferring pair effects as design evidence, the
UI requires a separate declaration that you reviewed experimental
comparability. The tutorial does not manufacture a ChEMBL assay identifier or
confirm a new compound's potency, synthesis, selectivity or ADME.
